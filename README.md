# Link

面向 Android 的相机连接与下载工具，支持 **Wi-Fi (PTP/IP)** 与 **USB (MTP)**，提供原片浏览、任务下载、色彩预设、水印、视频导出及尼康 GPS 同步。

## 功能

### 连接
- **Wi‑Fi 连接**：连接页三步操作指引（连接智能设备 → AP mode → 建立 Wi-Fi 连接）
- **USB 连接**：即插即用，通过 USB 数据线直接连接相机（需要手机支持 USB OTG）
- 记住上次连接的相机 Wi-Fi，连不上时自动跳转系统 Wi-Fi 设置
- 前台服务保持 Wi-Fi 连接不断开，Wi-Fi 锁防止息屏时相机热点休眠
- USB 诊断工具（设置页查看设备详细信息）

### 相册
- 按格式分类筛选（全部 / JPG / RAW / 视频）
- 多选批量下载
- 照片预览：双指缩放、拖拽、逆时针旋转
- 查看原图（从相机下载全分辨率）
- 预览内直接下载原图
- 分页加载，底部进度提示

### 下载
- 相册页创建下载任务，下载页展示缩略图与环形进度
- 实时显示已下载大小、剩余大小、速度与预计时间
- 支持取消任务、失败重试和重复下载提示，取消不会断开相机连接
- 下载页查看高清原图与视频（从本地加载，无需联网）
- 多选分享（QQ / 微信等系统分享面板）
- 多选删除（带二次确认）
- 按格式分类筛选（全部 / JPG / RAW / 视频）
- 下载通知进度条（实时百分比 + 进度条）
- 下载失败通知栏一键重试

### LUT 与导出
- 导入 `.cube`、Hald CLUT `.png` 与 `.xmp` LUT
- GPU 实时预览，照片支持 LUT 强度调节、缩放与旋转
- 照片支持 LUT、水印及二者组合导出，可批量处理
- 视频支持全屏有声播放、LUT 预览、旋转与硬件加速导出
- LUT 侧边栏可滚动、收起与展开

### 其他
- 动态 chunk 拥塞控制提升下载速度
- 下载后自动保存到系统相册
- 暗色主题（Bridge Night 配色）
- 水印叠加（EXIF 信息水印，可自定义位置与样式）
- 屏幕灯光：创建、保存和播放灯光场景

## 使用方法

### Wi‑Fi 连接
1. 在相机上开启 Wi‑Fi 热点（连接到智能设备 → AP mode）。
2. 手机连接相机 Wi‑Fi 热点。
3. 打开 Camera_Bridge，点击「开始建立连接」。
4. 连接成功后可浏览、预览和下载照片。

### USB 连接
1. 用 USB 数据线将相机连接到手机（相机需开启 MTP 模式）。
2. 打开 Camera_Bridge，自动检测 USB 相机。
3. 授予 USB 权限后即可浏览和下载照片。

> 小米设备建议将 Camera_Bridge 的电池策略设置为「无限制」，并关闭 WLAN 助理的自动切网功能。

## 已测试机型

### Link 1.0.27 缩略图缓存

- 相机缩略图写入手机本地预览缓存，内存未命中时优先从本地读取，只有缓存缺失或损坏才重新向相机读取。缓存保存已校正方向、去留边并缩放后的预览；手动加载原图得到的清晰缩略图也写入缓存。
- 使用相机信息和照片句柄、名称、文件大小、拍摄时间及尺寸区分缓存。本地缓存上限 128 MiB，按最近使用时间淘汰；刷新相册和重新打开应用不主动删除本地缓存，系统回收应用缓存时可能需要重新读取。
- 设置“存储”显示本地缩略图的实际文件占用。清理同时释放相机与本地照片的内存缩略图缓存，并防止清理前的加载任务重新写入；不删除已下载照片、原图或色彩预设。
- 磁盘缓存的持久化、替换计数、容量淘汰、清理及旧任务失效通过自动测试；相机连接后的滑动体验需要手机实测。

### Link 1.0.25 相册预览

- Wi-Fi 浏览时优先使用相机声明支持的 Nikon 大缩略图（GetLargeThumb）；明确不支持、无缩略图或返回数据无法识别时回退普通缩略图。连接异常不会在失去同步的会话上继续请求。USB 保持系统 MTP 缩略图接口。
- 相册只加载可见项目，显示缓存最长边限制为 960 像素，不因生成缩略图而下载整个原图。大缩略图的实际像素由相机决定，不承诺达到 SnapBridge 的 2MP 导出规格。
- 使用相机报告的照片宽高核对缩略图两侧或上下的连续对称黑色留边，仅在裁切后符合照片比例时去掉留边；未知尺寸、正常比例、全黑或不对称暗部保持原样。裁切只用于相册预览缓存，不改变原图、下载文件或色彩处理输入。
- 自动测试和构建可验证代码逻辑；Zf 返回大缩略图的实际清晰度和相册留边效果需连接相机后检查。
